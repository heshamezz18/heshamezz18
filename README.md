## How I approach automation

1. Understand the existing process and its repetitive steps.
2. Use deterministic rules for clear business requirements and AI where interpretation helps.
3. Validate inputs and outputs, and keep uncertain results available for human review.
4. Document setup, limitations and test coverage so others can reproduce the work.
